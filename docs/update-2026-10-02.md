## 计划与收支的统计口径

计划只记账，不调用银行或交易所，不执行真实资金划转。一次执行写入当前业务分钟，备注保留原到期时间；不向既有余额历史中插入过去的支出，避免覆盖当前余额。重复计划按原到期时间加固定天数推进，尚未补完时下一批继续；每月不是固定天数，请按需要选择间隔。

每项计划在 Serializable 事务内锁定计划行，然后按固定顺序锁定账户；余额记录、转账记录和计划推进同事务提交。确定的“计划 ID + 到期时间”执行标识及完成状态用于防重复执行。失败不推进计划，保留错误提示供重试。隐藏账户未解锁时不显示/执行有关计划；归档账户计划执行失败并保留。所有资源按会话用户隔离。

现有数据保存的是余额快照，日历因此采用“账户余额变动估算”口径，不能视为完整交易流水：资产账户增加为收入、减少为支出，负债账户相反。只统计 balance/correction/scheduled_expense；初始余额（包括被更正的第一条记录）、估值、账户内部转账和借贷本金配对变化不计入。手动更新欠款减少也会被估算为收入，页面已注明负债账户反向计算；精确的经营收入/消费统计需要后续显式收支记录模型。

按变动发生日的可用历史汇率换算，保留十进制精度后汇总至两位小数；缺少汇率则该日标记不完整，不把外币当本位币。月查询只重放该月历史并为每个账户读取月前最后余额；点击日期只读取该日记录，避免为每次点击重复传整月明细。

```powershell
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:migrate
pnpm build
pnpm --filter @worthpath/api icons:seed
pnpm test
pnpm test:integration
```
