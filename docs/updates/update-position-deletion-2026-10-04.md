# 独立资产与债务删除

账户、独立资产和债务详情均提供删除按钮。债务支持借入和借出两种方向；隐藏项目先通过网页解锁，归档项目也可以删除。

## 删除确认

删除前显示将移除的余额、估值或借贷历史及债务关联数量。必须输入完整项目名称才可确认。删除后更新资产总览、净资产趋势、历史和收支日历；该删除无法撤销。

若项目被转账、借贷、还款或定时计划引用，删除会被阻止。需要先撤销相关资金往来并删除计划，再删除项目；需要保留历史时可选择归档。不会级联删除配对资金往来，避免其他账户余额失真。债务与其他资产的普通关联可随项目删除，不会删除关联资产。

## 接口与数据

复用 GET /api/positions/:id/deletion 和 DELETE /api/positions/:id；删除请求为 confirmation 字段，必须与项目名称完全一致。服务端继续验证用户归属、隐藏可见性和关联记录，事务中锁定项目，删除成功后清理统计缓存。

不新增数据库表或字段，无需数据库迁移；已有注释保持不变。MCP 尚无项目删除工具，此功能由用户在网站操作，本次未修改真实用户的资产或债务。

## 验证

类型检查和生产构建通过；44 项单元测试、3 项真实 MySQL 删除与草稿测试全部通过。覆盖两种债务方向、独立资产、隐藏归档、名称确认、跨用户隔离、历史及关联清理、总览与日历联动，以及借贷/还款记录阻止删除时双方余额保持不变。测试账户已自动清理。
